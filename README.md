# 网格随机效果生成器

一个可在浏览器中运行的视觉编辑器：上传图片后，通过可配置网格生成随机拉伸、马赛克、错位、扫描线与颜色偏移效果，并可导出 PNG。

## 功能

- 上传 JPG / PNG / WebP
- 画布与网格设置
- 列数、行数、槽宽、页边距
- 网格线、坐标、装饰性文本
- 效果比例、强度、相邻 2×2 合并
- 多种随机效果类型
- 添加大标题
- 重新随机
- 高分辨率 PNG 导出

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建后会生成自包含的 `dist/index.html`，根目录 `index.html` 也会同步更新，可直接发布为静态网站。

## 项目结构

- `src/main.jsx`：交互与画布渲染
- `src/styles.css`：界面样式
- `src/assets/demo-portrait.jpg`：内置演示图
- `vite.config.js`：单文件离线构建配置
- `index.html`：可直接打开的构建成品
